# 🎬 Netflix Data Analysis

## 📖 Overview
This project explores and analyzes the **Netflix Movies and TV Shows Dataset** to uncover patterns, trends, and insights about Netflix’s global content library.  
Using Python’s data analysis and visualization libraries, it helps understand factors like **content type distribution**, **popular genres**, **top countries**, and **release year trends**.

---

## 🧠 Objectives
- Analyze the distribution of **Movies vs TV Shows**.  
- Identify the **most common genres** and **countries** represented.  
- Visualize **release year trends** and **content growth**.  
- Explore **ratings, durations**, and **popular directors/actors**.

## 📊 Dataset
The dataset used is the **Netflix Movies and TV Shows Dataset** from Kaggle.

**Columns include:**
- `show_id`  
- `type` (Movie / TV Show)  
- `title`  
- `director`, `cast`, `country`  
- `release_year`, `rating`, `duration`  
- `listed_in` (genres)  
- `description`
